# Levelling-Up 🚀

Welcome to my **Levelling-Up** repository! I created this space to stay consistent with my coding practice every single day, track my progress, and prepare for software engineering interviews.

## 🎯 Goals & Roadmap

My daily coding journey focuses on mastering the following core areas:

1. **Python Fundamentals** 🐍
   - Mastering basic and advanced Python concepts.
   - Understanding data structures, object-oriented programming, and Pythonic patterns.
   - Check out my [Python Basics](Python%20Basics/python%20basics.ipynb) notebook for a detailed beginner's guide!

2. **Data Structures & Algorithms (DSA)** 🧠
   - Building a strong foundation in core data structures (Arrays, Linked Lists, Trees, Graphs, Hash Maps) and algorithms (Sorting, Searching, Dynamic Programming).
   - Learning how to analyze time and space complexity (Big O Notation).

3. **Blind 75** 🏆
   - Conquering the classic [Blind 75](https://leetcode.com/discuss/general-discussion/460599/blind-75-leetcode-questions) LeetCode list to prepare for top-tier tech interviews.

4. **NeetCode 150** 🔥
   - Expanding on the Blind 75 with the [NeetCode 150](https://neetcode.io/practice) (the "blind 150"), which provides a more comprehensive coverage of essential interview coding patterns.

## 📈 Daily Consistency
The primary goal of this repository is consistency. By committing code daily, I am building the discipline and problem-solving skills needed to land a great job in software engineering!
